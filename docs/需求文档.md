# 3D AI NPC 智能哨兵 — LangGraph 驱动沉浸式感知决策系统 Demo 需求文档

## 1. 项目目标

构建一个在 UE5 3D 环境中运行的 **AI NPC 哨兵**，完全由本地部署的大模型 + LangGraph Agent 编排驱动。\
验证以下核心能力：

*   3D 环境感知 → 多步推理 → 行为决策的完整闭环

*   LangGraph 管理 NPC 状态、记忆、工具调用与断点恢复

*   通过 MCP 协议打通 Agent 与 UE 引擎层的双向实时交互

*   积累结构化私有数据，为模型微调与产品化做准备

***

## 2. 场景设定

*   **场景**：中世纪城堡大门前的庭院（3D 场景）

*   **玩家**：可自由移动的第三人称角色，可拔出/收回武器，可与环境物体交互（如点燃火把、翻倒木桶）

*   **NPC 哨兵“阿托”**：守卫城门的骨骼绑定角色，拥有完整的视觉感知、记忆与情感状态

*   **时间系统**：实时昼夜循环，影响 NPC 的视野范围和警觉度

***

## 3. 核心技术栈

| 层级       | 技术                                    | 作用                        |
| -------- | ------------------------------------- | ------------------------- |
| 前端交互     | UE5 (C++ / Blueprint)                 | 3D 渲染、物理、动画、行为树执行器        |
| 通信层      | HTTP Long-Polling / WebSocket         | UE 与 Agent 后端实时双向通信       |
| Agent 编排 | **LangGraph** + LangChain             | 状态图编排、记忆管理、工具调用           |
| 记忆系统     | **LangChain Memory** + 本地向量库 (Chroma) | 短期对话记忆、长期事件记忆             |
| 知识检索     | **LlamaIndex**                        | 城堡守则、世界知识 RAG             |
| 工具调用     | **MCP (Model Context Protocol)**      | Agent 安全调用 UE 中暴露的 C++ 函数 |
| 模型推理     | 本地 Ollama (Qwen2.5:7B)                | 私有化部署，决策推理                |
| 数据记录     | LangSmith / 本地 JSON                   | 决策轨迹自动存储，形成训练数据集          |

***

## 4. 感知系统（UE5 → Agent）

NPC 在 3D 环境中的感知由 C++ 组件每 0.5 秒采集一次，序列化为结构化 JSON 发送给 Agent。

### 4.1 感知字段定义

| 字段名                   | 类型     | 说明                                            |
| --------------------- | ------ | --------------------------------------------- |
| `player_distance`     | float  | 玩家到 NPC 的直线距离 (cm)                            |
| `player_visible`      | bool   | 玩家是否在 NPC 视野锥内                                |
| `player_weapon_drawn` | bool   | 玩家是否拔出武器                                      |
| `time_of_day`         | string | `"day"` / `"night"`                           |
| `nearby_allies`       | int    | 附近友方 NPC 数量                                   |
| `alarm_triggered`     | bool   | 警报是否已激活                                       |
| `last_player_action`  | string | 玩家最近一次交互行为（如 `"lit_torch"`, `"knocked_vase"`） |

### 4.2 感知数据输出示例

```json
{
  "timestamp": 1712400000,
  "player_distance": 450.0,
  "player_visible": true,
  "player_weapon_drawn": true,
  "time_of_day": "night",
  "nearby_allies": 0,
  "alarm_triggered": false,
  "last_player_action": "none"
}
```

### 4.3 AI决策驱动的3D行为表现（非语言层）

Agent输出的 `npc_animation`、`npc_movement`、`npc_gaze_target` 等指令，直接驱动NPC在3D空间中的行为，使观察者不依赖对话文本也能感知到AI的存在。

**关键3D行为指标**：

| 行为维度 | 无AI表现      | 有AI表现                  | 驱动方式                           |
| :--- | :--------- | :--------------------- | :----------------------------- |
| 安全距离 | 固定阈值触发     | AI根据威胁评估动态调整，主动后退或前进   | Agent输出 `npc_movement`         |
| 视线追踪 | 简单LookAt玩家 | 视线在玩家、武器、环境关键点之间自主切换   | Agent输出 `npc_gaze_target`      |
| 环境交互 | 无          | 自主使用火盆、桌子、警报器等场景物体     | Agent调用MCP工具触发                 |
| 情绪姿态 | 几个预设动画切换   | 身体后倾程度、手与武器的距离随情绪值连续变化 | Agent输出 `npc_emotion_blend` 参数 |
| 预测行为 | 仅被动反应      | 预判玩家意图，提前拦截或关闭城门       | Agent多步推理后的工具调用                |

## 5. LangGraph Agent 架构

Agent 作为独立 Python 微服务运行，提供 `/decide` 接口。核心是一个包含 **记忆检索、意图识别、威胁评估、工具调用、回复生成** 的状态图。

### 5.1 状态定义 (AgentState)

```python
class AgentState(TypedDict):
    # 输入
    perception_json: dict       # UE 发送的感知数据
    # 记忆
    conversation_history: list  # LangChain 管理的对话记录
    long_term_events: list      # 长期重要事件摘要
    # 中间推理
    intent: str                 # chat / warn / investigate / attack
    threat_level: str           # low / medium / high
    retrieval_result: str       # RAG 检索到的世界知识
    tool_calls: list            # 需要调用的 MCP 工具及参数
    tool_results: dict          # 工具执行返回结果
    # 输出
    npc_animation: str          # 动画状态 (idle, alert, draw_weapon, attack, ...)
    npc_dialogue: str           # NPC 对话/内心独白
    npc_movement: str           # 移动指令 (hold_position, advance, retreat)
```

### 5.2 节点与图结构

    [接收感知数据]
           │
           ▼
    [记忆检索节点] ← LangChain BufferMemory + 向量长期记忆
           │
           ▼
    [意图识别节点] ← 使用 LLM 判断当前玩家行为意图
           │
           ▼
    [威胁评估节点] ← 综合记忆、知识库、守卫守则评估威胁
           │
       ┌───┴───┐
       ▼       ▼
    [低威胁] [高威胁]
       │       │
       ▼       ▼
    [闲聊/  [工具调用节点] ← 调用 MCP: 拉响警报、呼叫支援、检查城门...
     提示]     │
       │       ▼
       │   [行动决策节点]
       │       │
       └───┬───┘
           ▼
    [回复生成节点] → 生成自然语言对话 + 动画指令
           │
           ▼
    [输出到 UE]

**关键实现**：

*   所有节点均通过 `StateGraph` 管理，支持 `checkpointer` 持久化

*   记忆采用 `ConversationSummaryBufferMemory` 保留关键信息，避免上下文窗口溢出

*   工具定义为标准 `Tool` 对象，通过 MCP 协议注册到 UE

## 6. 集成模块实现要点

### 6.1 LangChain Memory（短期 + 长期记忆）

*   **短期**：保留最近 20 轮对话，使用 `ConversationBufferWindowMemory`

*   **长期**：将玩家重大行为（如“曾经试图攻击”、“帮助过守卫”）存入 Chroma 向量库，检索时根据当前场景语义匹配历史事件

*   **更新策略**：Agent 在 `[记忆检索]` 节点后将关键事件摘要向量化写入 Chroma

### 6.2 LlamaIndex 知识库（世界规则 RAG）

*   **文档内容**：城堡守卫手册（如“夜间禁止靠近城门”、“携带武器者必须接受盘查”）

*   **索引**：`VectorStoreIndex` + 本地 Embedding 模型

*   **调用时机**：Agent 在 `[威胁评估]` 节点前检索相关守则，作为 LLM 推理的上下文

### 6.3 MCP 工具集（Agent 操控 3D 世界）

| 工具名称                 | 对应 UE 函数                                   | 描述          |
| :------------------- | :----------------------------------------- | :---------- |
| `trigger_alarm`      | `ATriggerAlarm::Activate()`                | 拉响城堡警报，召唤支援 |
| `draw_weapon`        | `UAnimInstance::SetWeaponState()`          | NPC 拔剑      |
| `move_to_location`   | `AAIController::MoveTo()`                  | 移动到指定坐标     |
| `interrogate_player` | `UDialogueComponent::StartInterrogation()` | 开启盘查对话模式    |
| `lock_gate`          | `ACastleGate::Close()`                     | 关闭城门        |
| `check_identity`     | `APlayerState::GetReputation()`            | 查询玩家声誉值     |

*   MCP Server 端由 UE 实现，Agent 通过 MCP Client 调用

*   Agent 在 `[工具调用]` 节点根据决策自动选择合适的工具

### 6.4 断点恢复与多会话管理

*   使用 LangGraph `MemorySaver` 保存每个 NPC 实例的状态

*   玩家离线后重新上线，NPC 可从上次决策中断点继续（保留心情、记忆）

*   支持同时运行多个 NPC 实例，各自独立状态

## 8. 演示流程（面试展示剧本）

1.  **白天巡逻**：玩家正常行走，阿托在城门前来回巡逻，看到玩家时会说：“日安，旅行者。请勿靠近城门。”

2.  **深夜警惕**：时间变为黑夜，阿托的手放在剑柄上。玩家靠近时立刻发出警告：“止步！夜间城门戒严。”

3.  **武器触发**：玩家拔出武器，阿托瞬间拔剑，进入战斗姿态，通过 MCP 拉响警报（场景中响起警钟声，远处出现火光）。

4.  **连续记忆**：玩家逃跑并收起武器，一分钟后再次接近，阿托会说：“我记得你，上次你试图袭击城门。这次我不会再给你机会。” 直接呼唤支援。

5.  **世界知识融入**：玩家问：“我听说有条密道可以进城？” 阿托检索守卫守则，回答：“没有这回事。你再散布谣言，我将逮捕你。”

6.  **数据记录**：打开调试面板，展示所有决策步骤、工具调用日志、存储的长期记忆条目。
